# 消防設備士乙種第6類・柴犬先生スマホ問題集 PWA

**Ver 1.0 / 作成者：電脳主夫**

指定された完成イメージをデザイン基準として、柴三郎先生・元気くん・ももちゃんの既存キャラクター画像を実際のHTMLで使用したPWA完成版です。

## 仕様
- 200問
- 1回50問を区分別に17 / 8 / 17 / 8で抽出してシャッフル
- 回答後約6秒で自動的に次の問題へ
- 問題表示から20秒で、ももちゃんのヒントを表示
- A/B/C火災区分の常時表示なし
- 閲覧カウンター・第三者のアクセスカウンター・アクセス解析は使用しない
- #消防設備士 #乙6 #試験対策 #消防 #資格 #勉強 #電気 #消火器 #鑑別 #無料アプリ
- アプリアイコンは柴三郎先生（192/512 PNG）
- スマートフォンでは画面を最大限使用し、端末の時計・バッテリー表示はスマートフォン側に任せる
- 問題番号・進捗カウンターは表示しない
- 不正解の場合も約6秒間、正解と解説を表示して自動的に次の問題へ進む
- ももちゃんのヒントは20秒後に回答ボタンと重ならない位置へ表示
