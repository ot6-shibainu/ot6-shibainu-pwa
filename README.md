# 消防設備士乙種第6類・柴犬先生スマホ問題集 PWA Ver 2.0

作成者：電脳主夫

## Ver 2.0
- オリジナル問題を合計250問収録。
- 1回35問：消防関係法令10問（法令共通6＋類別4）→基礎的知識5問→構造・機能及び整備15問→実技・鑑別等5問の順で出題。
- 問題は各分野からランダム抽出しますが、分野の順番は固定です。
- 回答後は解説を表示し、約6秒で自動的に次へ進みます。
- 問題表示から20秒後に、ももちゃんのヒントを表示します。
- スマートフォンの画面レイアウトは基準ZIP「新しいフォルダー.zip」をベースに維持しています。
- `questions.js` に問題データを内蔵しているため、`index.html` をPCで直接開いた場合でも問題データを読み込めます。
- GitHub Pages等のHTTPS環境ではPWAとしてService Workerによるキャッシュ利用が可能です。

## 著作権等について
本アプリは学習用のオリジナル問題集です。公式過去問題の文章・画像をそのまま転載するものではありません。消防試験研究センター等の公式機関とは関係ありません。

無断転載、販売、改造・再配布を禁止します。

試験制度・法令・規格は変更される場合があります。受験時は必ず最新の公式情報を確認してください。
