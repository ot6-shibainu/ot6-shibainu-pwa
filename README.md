# 消防設備士乙種第6類・柴犬先生スマホ問題集 Ver 2.0

作成者：電脳主夫

## 内容
- 全250問
- 1回35問：消防関係法令10（共通6＋類別4）、基礎的知識5、構造・機能及び整備15、実技・鑑別5
- 20秒後にももちゃんのヒント
- 解答後約6秒で自動的に次へ
- スマートフォン初回起動時のパスワード：8888
- 同じブラウザ・端末では認証後の再入力を省略
- PWAとしてHTTPS（GitHub Pages等）で利用可能
- `index.html` を直接開く場合も、問題データをindex.html内にも内蔵して動作する構成（questions.js単独読み込みに依存しない）

## 注意
このアプリは学習目的のオリジナル問題集です。公式試験機関との提携・監修を示すものではありません。過去問題の論点を参考にしつつ、問題文・選択肢・解説はオリジナル化しています。

## GitHub Pages
リポジトリ直下に本フォルダの中身をアップロードし、Pagesを `main` / root に設定してください。
