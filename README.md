# 消防設備士乙種第6類・柴犬先生スマホ問題集PWA

消防設備士乙種第6類の学習を目的とした、無料のスマートフォン向け問題集です。

## 📱 このアプリについて

本アプリは、消防設備士乙種第6類試験の学習を、スマートフォンで楽しく行うために制作した無料のPWA（Progressive Web App）です。

50問をランダムに出題し、各区分の理解度を確認できます。

### 出題区分

- 消防関係法令
- 基礎的知識（機械）
- 構造・機能及び整備
- 実技・鑑別

### 合格判定

全体の正答率が60%以上で、かつ4つの区分すべてで60%以上の場合を「合格」と判定します。

1つでも区分が60%未満の場合は、全体の正答率が高くても「不合格」と判定します。
