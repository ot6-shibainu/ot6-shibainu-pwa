# 消防設備士乙種第6類・柴犬先生スマホ問題集PWA

消防設備士乙種第6類の学習を目的とした無料のスマートフォン向け問題集です。

## Ver 2.0
- 250問を収録
- 1回の出題は35問
- 出題順：
  1. 消防関係法令 10問（法令共通6問＋類別4問）
  2. 基礎的知識（機械）5問
  3. 構造・機能及び整備 15問
  4. 実技・鑑別 5問
- 各区分からランダムに選びますが、上記の区分順は固定です。
- 全体60%以上、かつ各区分60%以上で合格判定
- 回答後は約6秒で自動的に次の問題へ
- 問題表示から20秒後にももちゃんのヒントを表示
- 1画面を基本としたスマートフォン表示
- PCでは縦長のスマートフォン画面を中央に表示
- `index.html`をPCで直接開いて確認できる構成
- Service Workerのキャッシュ名をVer 2.0へ更新

## オリジナルキャラクター
柴三郎先生・元気くん・ももちゃんは本アプリ用に用意したPNG画像を使用しています。
