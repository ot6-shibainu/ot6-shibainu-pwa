# 消防設備士乙種第6類・柴犬先生スマホ問題集PWA

消防設備士乙種第6類の学習を目的とした無料のスマートフォン向け問題集です。

## Ver 1.0
- 200問から毎回50問をランダム出題
- 出題区分：消防関係法令17、基礎的知識（機械）8、構造・機能及び整備17、実技・鑑別8
- 全体60%以上、かつ各区分60%以上で合格判定
- 回答後は約6秒で自動的に次の問題へ
- 問題表示から20秒後にももちゃんのヒントを表示
- 1画面を基本としたスマートフォン表示
- PCでは縦長のスマートフォン画面を中央に表示
- ローカルで index.html をダブルクリックしても問題データを読み込める構成

## オリジナルキャラクター
柴三郎先生・元気くん・ももちゃんは本アプリ用に用意したPNG画像を使用しています。

## PCブラウザー直接起動対応
Ver 1.0 PCスマホ画面・動作修正版では、index.htmlをPCで直接開いた場合でも問題データを読み込めるよう修正しています。キャラクターPNGはパッケージ内のimgフォルダに保存しつつ、表示はHTML内にも埋め込んでいます。
